# 💰 Expenses Vault

A modern and intelligent **Expense Tracker Web App** built with **React**, **TypeScript**, **Redux Toolkit**, and **Tailwind CSS** — to help you track, visualize, and manage your daily spending efficiently.

🔗 **Live Demo:** [https://joshinavin2001.github.io/Expenses-Vault](https://joshinavin2001.github.io/Expenses-Vault)

---

## 🚀 Features

✅ Add, edit, and delete expenses  
✅ Categorize expenses (Food, Travel, Shopping, etc.)  
✅ Filter by category or date  
✅ Real-time analytics with charts  
✅ Persistent storage (localStorage)  
✅ Clean and responsive UI  
✅ Dark mode ready

---

## 🛠️ Tech Stack

| Category         | Technologies             |
| ---------------- | ------------------------ |
| Frontend         | React + TypeScript       |
| State Management | Redux Toolkit            |
| Styling          | Tailwind CSS + shadcn/ui |
| Charts           | Chart.js                 |
| Hosting          | GitHub Pages             |

---

## ⚙️ Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/joshinavin2001/Expenses-Vault.git
cd Expenses-Vault
npm install
npm run dev
```
